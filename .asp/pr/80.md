# feat(feed): 播報紀錄匯出 CSV —— 目前畫面上那幾列，防公式注入

Closes #80

## 問題

值班交接或事後檢討時常要把「這段時間吉祥物念了什麼」貼進工單或報告。清單現在只能看，
不能帶走 —— 唯一的辦法是在畫面上框選複製，而那會把顯示用的時間字串（吃 locale、今天的還會
省略日期）一起帶走，也分不出哪一列是紀錄、哪一列只是本分頁念過的。

零後端（ADR-004）所以匯出必須完全在瀏覽器裡完成：不新增端點、不打任何網路請求。

## 做法

新增 `src/feed/feedCsv.ts`（**純函式**，137 行），消費 #79 `buildFeedRows` 的輸出；
下載那一步（Blob + `a[download]`）留在 `MascotPanel.tsx` 的兩支模組層函式裡，與格式分開。

| 匯出 | 做什麼 |
| --- | --- |
| `feedRowsToCsv(rows)` | 一整份 CSV 的字串：UTF-8 BOM ＋ 標題列 ＋ 每列「時間／來源／句子」，記錄間與結尾都是 CRLF |
| `csvCell(value)` | 一格的跳脫：RFC 4180 的引號與雙引號加倍，**另**對會被當公式的開頭加單引號前綴 |
| `feedCsvFilename({ dashboardUid, panelId, at })` | `augur-broadcast-<uid>-panel<id>-<UTC 戳記>.csv`，只留 `A-Za-z0-9_-` |
| `FEED_CSV_COLUMNS`／`FEED_CSV_ORIGIN`／`CSV_BOM`／`CSV_NEWLINE`／`CSV_FORMULA_PREFIX`／`FEED_CSV_MIME` | 格式的具名常數（測試逐字釘住，文件也照這幾個寫） |

元件那一側（`MascotPanel.tsx`）只有三處：

```tsx
// 1. 一輪 render 只算一次，清單與匯出鈕讀同一份 rows
const { rows: feedRows, emptyText: feedEmptyText } = buildFeedRows(feed, history, historyFilter);

// 2. 按鈕（門檻 roomy，與語音那兩顆同一個；清單空的時候 disabled）
{roomy && <button … disabled={feedRows.length === 0} data-testid="feed-export">匯出 CSV</button>}

// 3. 兩支模組層函式（在元件外面）
function exportFeedRowsAsCsv(rows, dashboardUid, panelId)  // 讀「現在」當檔名的時間戳；零列就回頭
function downloadTextFile(text, filename, type)           // Blob + a[download]，全專案唯一一處下載
```

### 匯出的就是「畫面上那幾列」—— 靠的是同一份 rows，不是兩邊各算一次

`buildFeedRows` 在 render 裡**只呼叫一次**，清單的 JSX 與匯出鈕讀的是同一個 `feedRows`。
篩選框一改，兩邊同時變；「畫面顯示一套、匯出另一套」在這個結構下不可能發生。
（這也是為什麼 `renderFeedLines` 不再自己呼叫 `buildFeedRows`。）

### `FeedRow` 多一個 `at`（唯一動到 #79 介面的地方）

CSV 的時間欄要機器讀得懂的時間戳，而 #79 的 `FeedRow.when` 是**給人看的**顯示字串
（`toLocaleTimeString`／`toLocaleString`，今天的還會省略日期）—— 從它回推不出時刻。
所以 `FeedRow` 多一個 `at: number`：紀錄列是 `entry.time`，本分頁的列是 `line.at`，
兩個都是**既有**的時間戳，`buildFeedRows` 仍然不讀「現在」。

這讓 `feedRows.test.ts` 裡**一行**既有斷言要跟著補欄位
（`expect(rows[1]!).toEqual({ key, origin, when, text })` → 多一個 `at: rec.time`）。
那是**加嚴不是放寬**：`toEqual` 本來就要求物件完全相符，少了這個欄位該斷言會紅。
其餘既有斷言一字未動。

### 防公式注入的前綴釘死為**單引號**（回應票上留言 (a)）

票文只說「要加上防公式注入的前綴」，沒說是哪一個。本票釘死 `'`（OWASP 的建議做法），
並且**把代價寫進文件**：那個單引號會出現在儲存格裡，貼回工單時看得到
（`src/README.md`〈Exporting the record〉有一段專講這件事）。常數是
`CSV_FORMULA_PREFIX`，測試對 `=`／`+`／`-`／`@` 四種開頭逐一比對字面值。

比票文嚴一點的兩處，理由寫在 `feedCsv.ts` 的註解裡：

- **前面有空白的 `=` 也加前綴**（`  =1+1` → `'  =1+1`）：部分試算表匯入時會把前置空白修掉，
  修掉之後 `=` 就又在開頭了。
- **定位字元與 CR 開頭也加前綴**：這兩個也在 OWASP 的清單上。

### 時間欄是 UTC 的 ISO 8601（回應票上留言 (c)）

`2026-10-18T09:00:00.000Z`，**不是**本地時區偏移。跨時區交接時「09:00」是誰的九點會被讀錯；
帶 `Z` 的那一欄在任何地方讀都是同一個時刻。要看本地時間的人在**畫面上**看（那一欄是
`FeedRow.when`，照舊吃 locale）。標題列把這件事寫出來：`時間（ISO 8601，UTC）`。
有一支測試直接否定本地偏移的寫法（`not.toMatch(/[+-]\d\d:\d\d$/)`）。

### dashboard uid 取不到時省略那一段（回應票上留言 (b)）

留言指出的風險是真的：`MascotPanel.tsx` 的取法是
`alertState?.dashboardUID ?? data.request?.dashboardUID`，而 12.3.0–12.3.11 的 `alertState`
只有數字 `dashboardId`、還沒存檔的 dashboard 也沒有 uid —— 兩個來源都取不到時，
檔名會長出 `undefined`。處置是**整段省略**（`augur-broadcast-panel7-20261018T090000Z.csv`），
時間戳壞掉同理。兩條各有一支測試，panel 那一側也有一支（用 12.3.x 形狀的 `alertState`）。

### 版面：窄面板不顯示匯出鈕（回應票上留言 (d)）

門檻與語音那兩顆同一個 `roomy`（>= 320×180）。窄於此時 head 會被擠成好幾列、body 也改成
上下堆疊，再多一顆按鈕只會更糟。**與語音鈕不同的是它不看 `enableTTS`** —— 關掉語音時清單
照樣在長，紀錄照樣要帶得走。有一支測試驗 300×160 時按鈕不存在、放大到 600×400 時出現。

### 另外三個決定（票文沒說，但一定得選一個）

- **UTF-8 BOM 寫在檔案最前面**。Excel 在 Windows 上讀沒有 BOM 的 CSV 會用系統舊編碼，
  中文句子整欄變亂碼 —— 匯出是要貼進工單的，亂碼等於沒匯出。BOM 放在純函式這一側
  （而不是下載那一步），「檔案長什麼樣」才有一個住處、測試也釘得到。
- **來源欄寫「紀錄」／「本分頁」**（AC-1 的用字），與畫面上的 `data-origin` 同一條分界。
- **空清單時回「只有標題列」的字串**，但畫面上按不到（按鈕 disabled ＋ 函式早退兩道）。
  純函式這一側不把「零列」當錯誤，呼叫端就少一條分支。

## QA 回合的修正（由 QA 直接改並 commit）

- **`feedCsv.test.ts` 一支測試名稱過度宣稱**：原名「三個欄位都過同一套處理 —— 來源與時間欄也不例外」，
  但來源與時間欄的值不可能以 `=`／`+`／`-`／`@` 開頭，所以讓那兩欄**繞過 `csvCell`** 的變異體
  能通過該測試（QA 實測：142 支全綠）。改名為「以 = 開頭的句子匯出之後，那一列沒有任何一欄還會被當公式算」
  ——它驗得到的就是這件事；lead 字元那一圈另補上 `-`。上面變異體表 M1 的測試名同步更新。
- **`filenameStamp` 的輸出沒過 `fileSafe`**：擴充年份的 ISO 寫法帶正負號
  （`new Date(8.64e15).toISOString()` → `+275760-09-13T…`），該段會把 `+` 帶進檔名，
  與「檔名只有 `A-Za-z0-9_-`」這條對外講過的規則不符（`src/README.md` 與檔名那組測試都如此宣稱）。
  從 UI 走不到（檔名的 `at` 一律是 `Date.now()`），但 `feedCsvFilename` 是匯出的函式、契約是無條件的。
  戳記改為最後再過一次 `fileSafe`（正常輸入全為英數，行為不變），並補一支邊界測試
  （QA 實測：拿掉那一道 `fileSafe` 時該支轉紅）。

- **AC-4 的「第二道防線」沒有測試釘得到**：`#80 AC-4：清單是空的時候匯出鈕 disabled，而且按下去不下載空檔`
  那一支的註解原本寫「程式裡還有一道早退 —— 直接呼叫 onClick 也不該下載」，但它走的是
  `fireEvent.click`，而 React 是依 `disabled` **prop**（不是 DOM 屬性）決定要不要送 click：
  從 DOM 把 `disabled` 拿掉再按也送不進 handler。QA 實測把 `exportFeedRowsAsCsv` 的
  `rows.length === 0` 早退整段拿掉，`npx jest src/feed src/components` 143 支**全綠**——
  那一道是純防禦，沒有測試釘得到。註解改成寫準這件事（擋住它的是 `disabled`、那一道早退從
  元件這一側走不到），AC-4 那一列也補上同一句。**沒有為了湊覆蓋率改 production**：早退留著
  （它的價值是「日後有人拿掉 `disabled` 時不靜默下載」，那是未來的事，不是現在驗得到的事），
  也沒有為測試把它 export 出來。
