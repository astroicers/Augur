## 問題

`MascotPanel.tsx` 1284 行,其中有三類東西與「接線 + 呈現」無關、卻只能跟著整個元件
一起讀、一起測:

**對外行為不變**:本票是純提取式重構,`MascotPanel.test.tsx` **一行都沒有改**。

### 樣式是逐字搬,而且驗過

`MascotPanel.styles.ts` 的 `getStyles` 本體是原檔 `:91–235` 的**位元組等同**複製
(唯一的改動是第一行多了 `export`),搬之前用 Python 對過一次
(把原檔 `:91–235` 取出、只把開頭的 `const getStyles` 換成 `export const getStyles`,結果必須是新檔的子字串)。
註解、空行、那段「⚠️ 這裡**不能**有 `align-items: flex-start`」的踩坑紀錄都原樣帶走。

順手修了一個**位置**錯誤(不是內容):原檔 `:82–90` 那段「呈現 + 接線。導播那條管線……」
的 JSDoc 掛在 `const getStyles` 上面,但它講的是元件 —— 這次把它移到
`export const MascotPanel` 正上方,一個字沒改。

### `muteStore`:ADR-007 的相容面釘進測試

```ts
export const MUTE_STORAGE_KEY = 'augur-mascot-panel.muted';   // 不得更名
export const MUTE_EVENT = 'augur-mascot-panel:muted';          // 不得更名
readMuted()                  // 讀不到／讀拋例外 → false
writeMuted(muted)            // 寫拋例外 → 吞掉(只在這次分頁內有效)
publishMuted(muted)          // 寫本機 + 發同頁事件;寫入失敗照發
mutedFromStorageEvent(e)     // 不是我們那個鍵 → null(過濾條件住在這裡)
watchMuted(cb): () => void   // 訂閱同頁事件 + 其他分頁的 storage 事件
```

兩個決定值得記:

- **過濾條件搬進模組**(`mutedFromStorageEvent`),不留在呼叫端。`storage` 事件是全域的,
  同一頁上 Grafana 自己與別的 plugin 寫本機都會進來;比錯鍵的後果是**被別人的設定靜音**。
  現在它有三支測試(我們的鍵、別人的鍵、`key` 是 `null` 的清空事件)。
- **`publishMuted` 把「寫本機」與「通知同頁」綁在一起**。原本是呼叫端兩行
  (`writeMuted` 然後 `dispatchEvent`),綁起來之後不會有人只做一半;而且
  「寫入失敗時事件照發」這條(靜音在本頁仍即時生效、只是不持久)變成模組的保證,
  有自己的測試,而不是靠元件那一側的呼叫順序。

`watchMuted` 回傳解除訂閱的函式,元件那一側 15 行的 effect 縮成一行
`useEffect(() => watchMuted(applyMuted), [applyMuted])` —— 兩個 listener 的註冊與移除
配對不再散在元件裡(漏掉一個的後果是 unmount 後還 setState)。

### `errorText` 放 `src/sources/`,`unavailableSpeaker` 放 `src/speech/`

票文 AC-3 只說「各自合理的位置」,這是本票唯一要自己選去處的一條。選法與理由:

- **`unavailableSpeaker` → `src/speech/unavailableSpeaker.ts`**:吃 `SpeakerEvents`、
  回 `Speaker`,兩個型別都是 `src/speech/` 的。擺在元件裡等於讓接線層定義播報器的一種實作,
  而且 `createRemoteSpeaker` 的降級路徑要繞回元件拿。
- **`errorText` → `src/sources/errorText.ts`**:它要認的那個非 `Error` 形狀
  (`{status, statusText, data.message}`)是 `getBackendSrv()` 的拒絕值,而全專案只有
  來源層在打 Grafana 的 HTTP API(`rulesFetcher`／`historyFetcher`)—— 「那個形狀長什麼樣」
  是來源層的知識。放 `core/` 不對:`core/` 是**來源中立**的核心,不該認得 Grafana 的 HTTP 形狀。

`unavailableSpeaker` 兩支,`formatWhen` 判為**已完成**、不重做(重做會把 #79 的注入點拆掉)。
