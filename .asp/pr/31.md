# docs: ARCHITECTURE、README、src/README、CHANGELOG 與程式現況對齊

Closes #31

## 問題

文件自 2026-10-06 起落後於程式。最要緊的是 `docs/ARCHITECTURE.md` 違反它自己的維護規則
(「動到資料流或新增 panel option 時同步更新資料流圖與檔案表」):ADR-005/006 帶進來的
四個模組(`sources/history.ts`、`sources/historyFetcher.ts`、`speech/remoteSpeaker.ts`、
`avatar/flap.ts`)在資料流圖與檔案表裡都不存在,〈設定〉少列 `ttsEndpoint` / `ttsTimeoutSec`,
ADR 索引沒有 ADR-006。另外三處是寫死的數字與自相矛盾的句子(見下)。

## 做法

### `docs/ARCHITECTURE.md`

- 檔頭「最後更新」改 **2026-10-14**,並記本次動了什麼。
- 〈一句話〉補外部語音與播報紀錄;加一句但書說明視線追蹤的計算在、但定稿素材
  `features.gaze = false` 所以畫面上看不到。
- **資料流圖**補三條路徑:`speaker.ts → remoteSpeaker.ts`(ttsEndpoint 非空時改走,
  逐句 `POST /v1/audio/speech`、Web Audio 播、那一則失敗或逾時退回 Web Speech)、
  `onboundary → flap.ts → setMouthOpen`(擺動次數不是振幅),以及一個獨立的
  **播報紀錄**區塊(annotations + rules + ruler 三個端點 → `historyFetcher.ts` →
  `history.ts` → feed,組句走同一支 `buildBroadcastPlan`,永不進語音佇列)。
  嘴型那一支按實作畫:外部語音是**音量包絡直接驅動 `setMouthOpen`、繞過 flap**
  (`MascotPanel.tsx` 的 `onMouth` 先 `flap.stop()`),不是兩者共用 flap。
- **檔案表**補上那四個模組;`src/core/` 那列與〈關鍵設計〉的「273 行、零修改」改寫
  (見下方 AC-1);過期的 `tools/` 那列改指向 README 的目錄表。
- **〈設定〉改成 12 列的表**,以 `src/module.ts` 的 `setPanelOptions` 為權威,逐項附預設值。
- **ADR 索引**補 ADR-006,並在節首明寫「本節是索引的唯一維護處」(AC-2)。
- 〈技術棧〉拿掉寫死的測試數,改指向 `bash tools/asp-test.sh` 的輸出。
- 〈已知缺口〉的「精靈圖 avatar 未做(P5)」換成現在真正的缺口:視線格未畫、
  手繪素材的三個門檻未校準。
- 〈維護規則〉加兩條:ADR 索引只在本檔維護;不要寫死會漂的數字。
