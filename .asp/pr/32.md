# docs(adr): ADR-007 語音開關（Retrospective）—— v0.2.1 的三項設計決策補進 ADR

Closes #32

## 問題

v0.2.1 的語音開關（#25、PR #26／#27）帶進三項設計決策，但只寫在 CHANGELOG 0.2.1、
`README.md` 與 commit 訊息裡，**沒有任何 ADR** —— 違反 `docs/ARCHITECTURE.md`〈維護規則〉的
「決策改變 → 先動 ADR（新增／supersede `docs/adr/`），再回頭同步本檔」。

同時 ADR-005 的 G-ADR005-2 仍寫「沿用既有『啟用語音』鈕」，而那顆按鈕已在 v0.2.1 被語音開關取代。

## 做法

### 新增 `docs/adr/ADR-007-voice-switch.md`（`Retrospective`）

依既有 ADR 格式（第一行 HTML 註解、狀態／日期／決策者表、〈痛點 / 需求〉→〈決策〉→
〈接受的代價〉→〈不採用的選項〉→〈Verification Evidence〉→〈Follow-up / POC gate〉→〈待驗風險〉）。
三項決策各自一節，各帶理由與一張「被否決的替代」表。

另加兩節，既有 ADR 沒有但本檔需要：

- **〈實作位置〉**：一張對照表，把每項決策落到 `src/components/MascotPanel.tsx` 的常數／函式名
  （`MUTE_STORAGE_KEY`、`MUTE_EVENT`、`BLOCKED_REPLAY_WINDOW_MS`、`AUTOPLAY_BLOCKED`、
  `readMuted` / `writeMuted`、`applyMuted`、`toggleVoice`、`blockedRef`、`PREVIEW_PLANS`、
  `voiceBlocked`）。依 ROADMAP〈引用規則〉（`docs/ROADMAP.md:67`「引用一律用檔案路徑與章節名」），
  **不用行號**。
- **〈Verification Evidence〉只列既有的元件測試**，14 條逐字抄自
  `src/components/__tests__/MascotPanel.test.tsx`，並明寫一行警告：這些都是 jsdom 下的測試，
  真瀏覽器的 autoplay 政策、真 `localStorage` 的 `storage` 事件、真的聽到補念**都還沒有機械證據**。
  不讓「測試是綠的」被讀成「真環境驗收過了」。

### `docs/adr/ADR-005-optional-external-tts.md`：G-ADR005-2 加一則補註

在〈Follow-up / POC gate〉的 G-ADR005-2 條目下加一個引用塊，註明「啟用語音」鈕已於 v0.2.1
由語音開關取代、解鎖手勢改由那顆鈕提供、外部語音被擋的判定改看 `autoplay-blocked`，並指向 ADR-007。
**ADR-005 的決策內容與狀態（`Accepted`）一字未動**；補註也說明 G-ADR005-2 原本的 PASS 證據仍然有效
（解鎖路徑沒變，只有觸發它的按鈕換了）。

### ADR 索引補 ADR-007

見下方 AC-4 的判讀說明。
